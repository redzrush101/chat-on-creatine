
## Install

| Platform | File |
| --- | --- |
| Windows | `Chat-on-Creatine-Windows-<arch>-Setup.exe` |
| macOS | `Chat-on-Creatine-macOS-<arch>.dmg` (Apple Silicon: `arm64`, Intel: `x64`) |
| Linux | `Chat-on-Creatine-Linux-<arch>.AppImage` or `.deb` |

The builds are not signed. On macOS, open the app once with right-click → Open, or run
`xattr -dr com.apple.quarantine "/Applications/Chat on Creatine.app"`. On Windows, SmartScreen
may ask you to confirm (More info → Run anyway). On Linux, `chmod +x` the AppImage.

`SHA256SUMS.txt` lists the checksum of every file. The companion extension for running ChatGPT
in your own Chrome is `Chat-on-Creatine-Extension.zip` (load it unpacked).
